How this prototype is built: one static HTML page, no backend — persistence that would live in SQLite on-device (rosters, remembered names, saved sessions, your collection, theme choice) is stood in here with the browser's local storage, scoped privately to your browser, so it survives a refresh but not a device switch. Photos in Session Saver and the Collection are downscaled and stored as data locally — there's no server upload. "Who Goes First?" reads real multi-touch via Pointer Events, so it plays out properly on a phone or tablet; the demo button on that screen fakes multiple fingers for testing with a mouse. Soundtrack items open a YouTube search in a new tab, matching the PRD's deep-link behavior. Source order and field logic follow BoardMaster_PRD.md and its companion prompts document exactly.
